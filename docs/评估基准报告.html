3. 确定性等价架构与 L2 覆盖扩展

端到端判定不依赖任何相似度阈值，由 src/provenance/exact_verifier.py 做三级布尔裁决；本版将 L2 结构匹配从「仅函数体」扩展为三类结构层级，进一步收窄覆盖边界：

层级判定覆盖改写
L1 规范型精确相等去注释 / 标识符归一 + VAR_n/FUNC_n→ID 占位折叠空白 → 规范型相等逐字克隆、变量 / 函数改名（T1/T2）
L2a 函数体结构包含KB 函数完整规范语句序列以保序子序列出现于查询函数体（容忍噪声插入任意位置）near-miss 插入式改写（T3）
L2b 类体结构包含类属性赋值（保留左值属性名，右值规范化）+ 方法签名（不含方法体）的保序子序列配置类 / 类属性克隆，改名类 / 方法仍命中（T5）
L2c 模块级结构包含纯模块级片段（无函数 / 类）的完整语句序列，保守要求 ≥ MIN_MODULE_STMTS=4 条防通用 import 误报模块级克隆（T6）
L3 锚点行游程≥ min_anchor_lines=3 行连续规范化行命中（召回闸门）语句删除 / 重排后残留 ≥3 连续行（T4-delete / T4-reorder）

主证据融合（次优证据融合：布尔判定门控 × 相似度排序）

为收窄真实跨项目归属歧义残差，v3.1 引入主证据融合（`src/pipeline.py` 的 rank_primary / attribution_of，配合聚合层「异源证据不合并」）：

  • 聚合层（segment_aggregator）：不同来源的证据即使重叠 / 相邻也各自成段——每段单一来源、source / license / verification_level 一致，避免「把正确来源吸收进伪匹配段而掩盖」；同源证据（间隔 ≤3 行）合并，score 取最高相似度、level 取最强；
  • 主证据排序（rank_primary）：段均为确定性验证产物（布尔判定先门控），在其上按 (similarity 最高, verification_level 最小, source) 排序，段[0] 为主证据段（is_primary）。相似度主导的理由：真实跨项目场景中，小段结构伪匹配（如 L2 包含）的相似度（实测 0.09–0.17）远低于正确来源（0.71–1.00），仅按布尔级排序会把伪匹配误判为主证据；相似度为 MinHash 估计值、只用于排序与展示，与「不参与克隆裁决」的既有设计一致，决策路径仍无浮点阈值；
  • 归属歧义（attribution_of）：存在不同来源的段与主证据段在 (level, similarity) 上完全并列（精确相等）时置 attribution_ambiguous=True（不静默、报告显式标记，审计者复核）；同源多段不计歧义。双基准实测无任何歧义用例。
跨文件多源召回：cross_file 变体拼接多个 KB 实体（requests + numpy + flask）为多源查询，ground truth 的 expected_project 为列表；端到端判定要求所有源均被召回（多源召回）。 负样本构造：真实语料负样本经确定性验证器全证据零匹配过滤——对每个候选逐一比对全部 KB 实体，L1/L2/L3 任一命中即剔除，覆盖单语句 L2 过度匹配等全部判定路径，从构造上保证零假阳性。

5. 合规判定准确率

合规推理（OSADL 矩阵 + Copyleft 规则 + 复合许可证拆分）在双基准、确定性架构下所有查询上 100% 正确（准确率 1.0000）。真实语料中 numpy / pandas 复合 SPDX 含 OSADL 未收录成分（0BSD / CC0-1.0）时系统保守判 NEEDS_REVIEW（正确行为）；本基准以其主许可证 BSD-3-Clause 为代表参与确定性合规度量，复合许可证解析本身由 matrix_loader 覆盖（另测）。

5.1 主证据驱动的合规聚合（混合许可证基准误报量化）

6. 诚实局限（论文须交代）

  • 双基准均为 Python、静态结构判定：不覆盖语义等价重写（T4，法律上属独立派生作品）与重度交错改写（语句 A,B,C → A,X,B,Y,C 且行级游程 < 3）。此类情形不静默判定，报告经 verification_level 显式暴露证据强度。
  • 覆盖边界（确定性架构残差）：L2 要求 KB 结构序列完整按序出现——语句被删除 / 重排的部分改写跌出 L2（由 L3 锚点游程捕获）；类体匹配要求保留类属性 + 方法签名结构（删属性 / 删方法签名跌出；v4.2 起方法签名含方法名——方法名重命名的类克隆跌出 L2b，由 L3 锚点兜底，换取消除「无参方法哈希碰撞」伪匹配）；L2a 仅对模块级函数生效（类内短方法体不再产生 L2 强证据）；模块级匹配仅对纯模块片段启用。
  • 真实跨项目结构近邻（归属歧义已收窄）：真实代码间存在结构相似的函数时，验证器必能检出克隆（正确项目仍在证据中，端到端召回不受影响）。v3.1 的主证据融合（布尔判定门控 × 相似度排序）将弱结构伪匹配（小段 L2 包含、相似度 0.09–0.17）与正确来源（0.71–1.00）正确区分，归属准确率双基准实测 1.000；仅当不同来源在 (level, similarity) 上完全并列时才置 attribution_ambiguous=True（报告显式标记，审计者复核）。合规结论不受该归属歧义影响；v4/v4.1 已落地主证据驱动的合规聚合（弱证据段不参与结论），真实 GPL/MPL/LGPL 混合基准误报 149→0。
  • 真实语料规模与选择偏好：KB 为 11 个真实包中「函数体 5–40 语句 / 类体 ≥2 成员」的中等规模实体（111 个），非整库全量；numpy / pandas 复合 SPDX 以主许可证为代表；溯源召回为全库确定性 Jaccard 扫描（非近似检索，召回确定性 100%），KB 规模 O(百) 文件下实测毫秒级，远高于 LSH Forest 亚线性代价生效的 2000+ 文件阈值，故 Forest 已于 2026-08-23 移除。
  • 单语句 L2 特异性：超通用单语句（如 return a + b）存在过度匹配风险，由验证级分级与证据强度标注兜底；真实语料负样本经验证器零匹配过滤后实测零假阳性。

7. 论文可用性与改进建议

  • 可写结论："在受控合成基准（n=57）与真实开源语料基准（n=484，11 真实包 / 111 实体，含 GPL·LGPL·MPL 不兼容正向用例）上，覆盖精确 / 改名 / near-miss / 语句删除 / 语句重排 / 类属性 / 跨文件克隆共 7 类改写，端到端克隆召回、确定性证据率、归属准确率与合规判定准确率均达 100%（多特征 MinHash 相似召回（运算符感知分词 + Winnowing 指纹 + AST 子树哈希）溯源粗筛 + 确定性等价验证器 L1/L2a/L2b/L2c/L3 布尔裁决，决策路径无浮点阈值；L2 已扩展至函数体 / 类体 / 模块级三层结构，L2a 仅模块级函数、L2b 方法签名含方法名 + 空壳类门槛）。"
  • 须诚实交代："1.00 为可控基准结果；确定性保证覆盖逐字 / 重命名 / 插入式近邻改写 / 类属性克隆，重度交错改写与语义等价重写（T4）为残差；真实跨项目结构近邻的归属歧义已由主证据融合收窄（归属准确率实测 1.0），弱伪匹配不参与合规结论（真实 GPL/MPL/LGPL 混合许可证基准误报 149→0）。"
  • 建议改进：① 在 ≥2000 文件整库语料上实证全库确定性扫描的常数开销与锚点索引规模代价（Forest 已移除，仅作规模边界标注）；② 干扰项目选取偏「弱近邻」采样（仅保留与目标 L3 匹配的真实函数），真实混合 KB 中 GPL/MPL 包与参考项目结构差异更大时的误报率分布仍待更大规模实证；③ 真实语料 KB 实体为「中等规模」采样（函数 5–40 语句），超大/超小实体（巨类、单行函数）的判定行为待专项基准。
