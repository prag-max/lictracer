2.3 安全控制实测

  • 上传大小上限：默认 5 MB（LICT_MAX_UPLOAD_BYTES），读取截断至 MAX+1 字节并返 413；已验证环境变量接线（设为 1048576 后常量生效）。
  • 可选 Bearer 鉴权：LICT_API_TOKEN 未设→匿名可访问（本地/内网）；设置后无/错 token→401，正确 token→200。
  • 后缀白名单：非 .py 上传→400。
  • LLM 默认关闭：未显式 LICT_ENABLE_LLM=1 时不调用任何第三方 API，仅本地模板；LICT_LLM_MASK_SOURCE=1 可脱敏来源。
  • 缓存防投毒：索引缓存为 JSON（hashvalues 数组），含 datasketch_version 指纹；启动自动删除 legacy .pkl；磁盘实测无 .pkl。
  • 最小权限：Dockerfile 以非 root appuser（uid 10001）运行。
  • 无 sys.path hack：全仓 grep 0 处，安装可复现性已落地。

四、未验证项与风险（诚实声明）

高风险 / 须补验

  • Docker 镜像构建与容器运行：本沙箱无 docker 引擎，未能执行 docker compose build 与启动冒烟。Dockerfile 两阶段构建、--no-deps -e .、非 root、mem_limit、--workers 1、healthcheck、回环地址绑定均已审查，但需在目标部署环境实跑确认。

中风险 / 已知局限

  • 大规模 KB 性能（诚实边界）：Forest 已于 2026-08-23 移除，溯源改为全库确定性 Jaccard 扫描（召回确定性 100%，KB O(百) 文件实测毫秒级）；遗留边界为全库扫描常数开销随 KB 文件数 N 线性增长，≥2000 文件整库代价仍待实证。
  • 上传上限行为化测试：大小限制逻辑与 env 接线已验证，但未用真实 >5MB 文件触发 413（低风险）。
  • 并发安全：tree-sitter threading.local 解析器隔离已在前期 8 线程验证；本轮未复跑，但代码与单测保持。

五、发布建议

结论：系统已具备发布条件，建议以「v0.1.0 候选」推进部署，但须先完成下方“部署前必做”。

  • 部署前必做（阻塞项）：在目标环境执行 docker compose build 与启动冒烟（/health 应返回 retriever_ready:true），确认镜像可构建、容器以非 root 启动、端口仅绑回环。
  • 部署前建议：以 ≥2000 文件的知识库跑一次端到端，验证 Forest 路径与兜底；按需设置 LICT_API_TOKEN 开启鉴权；如启用 LLM 摘要，显式设 LICT_ENABLE_LLM=1 并评估 LICT_LLM_MASK_SOURCE。
  • 论文层面待补（用户约定范围外）：评估 harness（召回率/精度量化）、多语言扩展；这两项为已知局限，应在论文“未来工作/局限性”中如实说明。
